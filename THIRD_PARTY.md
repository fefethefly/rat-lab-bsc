# Third-party provenance and publication boundary

RAT LAB adapts concepts from [Labrat](https://github.com/LabratDevRH/labrat) at commit `345274664716adae2a5d7955da02fb7a1f9d1aaa`. The upstream repository reports no repository-wide license. This public repository therefore does not include its code, trained weights, model assets, replay recording, or adapted 3D viewer. The public-source build displays an original static RAT LAB mascot illustration. Its visual behavior differs from the hosted site, which currently displays a labeled upstream reference recording.

The BSC/Flap integration, RAT LAB interface, local signing safeguards, and publication flow here were written for RAT LAB. MIT applies only to original RAT LAB material in this repository. It does not grant rights to Labrat, DeepMind, Flap, or any referenced project. Dependencies retain their own licenses. The Four.meme ABI license is reproduced in `server/FOUR_DOCS_LICENSE`; that legacy module is retained only for receipt compatibility.

A full neural-run reconstruction requires separately obtained rights to the upstream source and weights. Do not treat the static public-source build as a reproduction of the full private research environment.
