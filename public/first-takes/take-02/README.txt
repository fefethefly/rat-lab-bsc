RAT LAB — The long way home

Open player.html directly in a modern browser. Press Rebuild & verify, then Play. No server or RAT LAB connection is required. The HTML contains the score and complete synthesis code. Browser playback begins only after a click.

For full source verification: node verify.mjs (Node 18+). This verifies the archived source fingerprint, mapping from trajectory to events, packed score, renderer, WAV and cover. Hashes establish consistency with this manifest, not independent evidence that the operator ran the model honestly.

Behavior sonification: pitch follows vertical cursor position; horizontal position affects velocity; speed affects note duration. Event timing follows sampled motion, with a 200ms minimum spacing and 650ms repeat gate. No physical piano or independently trained composition policy. All four planned attempts were retained.

This is an unminted research candidate, not an asset sale or a copyright transfer. The testnet prototype uses separate test-only tokens. No price, royalty or resale promise.
